# Recorded voice clips

Put recorded clips here and list each file name in `recordedClips` in `js/data.js`.
Any letter, word or message without a clip is spoken by the device voice.

| Clip | File name | What to say |
|------|-----------|-------------|
| Letter | `letter-a.m4a` … `letter-z.m4a` | The Indonesian letter name: a, be, ce, … ki (Q), fe (V), eks (X), ye (Y), zet (Z) |
| Word | `word-a-1.m4a`, `word-a-2.m4a`, … | Each picture word, numbered by its place in the letter's `words` list in `js/data.js` (A: 1 Apel, 2 Anjing, 3 Ayam, …) |
| Celebration | `hebat.m4a` | "Hebat! Kamu sudah hafal semua huruf!" |

iPhone Voice Memos `.m4a` files work as they are; `.mp3` and `.wav` work too.
Trim silence at the start and end so the letter and word flow together.
